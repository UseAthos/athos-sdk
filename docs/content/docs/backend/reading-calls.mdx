---
title: Reading calls
description: All calls for an agency, all calls for a rep, and the detail plus score of one call — one source per request, practice or real.
---

Two endpoints, both server-to-server with your API key: a slim **list** that answers "all calls
for this agency" and "all calls for this rep", and a full **detail** for one call's transcript,
score and recording. Practice calls (`roleplay`) and an agency's real calls (`real_call`) have
**the same shape** — every row carries its `source`, and the roster ids on it are what let you
group by agency and by rep — and you read them **one source at a time**: `source` is required on
the list, so a request is either a practice history or a real-call history, never both mixed.

## List — `GET /v1/calls`

Returns **scored** calls of **one source** for your tenant, newest first (`roleplay` by `endedAt`,
`real_call` by `startedAt`), cursor-paginated.

**Query parameters**

| Param | Required | Notes |
| --- | --- | --- |
| `from` | ✅ | Lower bound (ISO 8601) on when a `roleplay` call **ended** / a `real_call` **started**. |
| `source` | ✅ | Which pillar to read: `roleplay` (practice calls) or `real_call` (an agency's [real calls](/backend/real-call-analysis)). One per request; omitting it is `400 INVALID_REQUEST` ("source is required: roleplay or real_call"). |
| `to` | | Upper bound (ISO 8601) on when a `roleplay` call **ended** / a `real_call` **started**. |
| `agencyId` | | **All calls for one agency**, by its Athos id (`athos_agency_…`). Checked against your roster: an unknown or foreign id is `404 AGENCY_NOT_FOUND`. |
| `agentId` | | **All calls for one rep**, by their Athos id (`athos_agent_…`). Checked against your roster: an unknown or foreign id is `404 AGENT_NOT_FOUND`. With an `agencyId` the rep is not in, the page is empty. |
| `platformAgentId` | | Filter to one rep by the `platformAgentId` you registered them under. An unknown value is an empty page. Not together with `agentId`. |
| `platformAgencyId` | | Filter to one agency by the `platformAgencyId` you registered it under. An unknown value is an empty page. Not together with `agencyId`. |
| `limit` | | Page size, default `50`, max `100`. |
| `cursor` | | Opaque token from a previous `nextCursor`. |

<Callout type="info">
  **Two filter pairs, four different values.** `agencyId` / `agentId` are *Athos* ids and are
  **checked**: asking for an agency or rep that is not yours is a `404`, never an empty page that
  would read as "no calls". `platformAgencyId` / `platformAgentId` are *your own* ids — the same
  names you registered them under — and are plain filters: an unknown value is an empty page.
  Name each rep (and each agency) one way per request: `agentId` **or** `platformAgentId`,
  `agencyId` **or** `platformAgencyId`; both is `400 INVALID_REQUEST`. Neither pair is required.
</Callout>

**Response** — a slim row per call (no score, no transcript):

```json
{
  "data": [
    {
      "id": "athos_call_GZ1DjOkZv_VEPoE-CJ8mp",
      "source": "roleplay",
      "agencyId": "athos_agency_V1StGXR8Z5jdHi6B-myT",
      "agentId": "athos_agent_bR4kQ2wZ9Lp0nH3xVq1Yt",
      "platformAgentId": "rep_8842",
      "platformAgencyId": "acme-7731",
      "drillKey": "ma-full-sale",
      "startedAt": "2026-06-05T14:39:40.295Z",
      "endedAt": "2026-06-05T14:49:52.295Z",
      "durationSec": 612,
      "scoredAt": "2026-06-05T14:50:29.005Z"
    }
  ],
  "nextCursor": "eyJ0IjoxNzQ5…"
}
```

`nextCursor` is `null` on the last page. Pass it back as `cursor`, with the same `source`, to page
through.

**Identity fields** — on every row, and on the detail below. One vocabulary everywhere: `agentId` /
`agencyId` are Athos's ids, `platformAgentId` / `platformAgencyId` are yours — the same names you
register with, mint with and filter by.

| Field | What it is |
| --- | --- |
| `agencyId` | The Athos id of the agency this call belongs to (`athos_agency_…`). |
| `agentId` | The Athos id of the rep who took the call (`athos_agent_…`). |
| `platformAgentId` | The id you registered that rep under, or `null` if you didn't register one — join on `agentId` in that case. |
| `platformAgencyId` | The id you registered that agency under, or `null`. |

<Callout type="warn">
  **`from` and `to` filter on the call's own time, not on when it was scored** — when it *ended* for
  a `roleplay` call, when it *started* for a `real_call` (a real call's `endedAt` is derived as
  start + duration) — and results come back newest first on that same axis. Scoring finishes some
  minutes after the call ends, so a call can become readable inside a window you have already read
  past. A watermark that only ever moves forward will silently skip those calls — when you
  reconcile, re-scan a window that overlaps the last one by an hour plus the longest real call you
  expect, and deduplicate on `id`.
</Callout>

<Tab value="curl">
```bash
# every practice call for one agency (source=real_call for its real calls)
curl -G https://app.useathos.ai/api/external/v1/calls \
  -H "Authorization: Bearer $ATHOS_API_KEY" \
  --data-urlencode "from=2026-06-01T00:00:00Z" \
  --data-urlencode "source=roleplay" \
  --data-urlencode "agencyId=athos_agency_V1StGXR8Z5jdHi6B-myT" \
  --data-urlencode "limit=50"
```
</Tab>
<Tab value="Node">
```ts
async function* callsFor(
  from: string,
  source: 'roleplay' | 'real_call',
  scope: { agencyId?: string; agentId?: string },
) {
  let cursor: string | null = null;
  do {
    const url = new URL('https://app.useathos.ai/api/external/v1/calls');
    url.searchParams.set('from', from);
    url.searchParams.set('source', source);
    if (scope.agencyId) url.searchParams.set('agencyId', scope.agencyId);
    if (scope.agentId) url.searchParams.set('agentId', scope.agentId);
    if (cursor) url.searchParams.set('cursor', cursor);
    const r = await fetch(url, { headers: { Authorization: `Bearer ${process.env.ATHOS_API_KEY}` } });
    if (r.status === 404) throw new Error((await r.json()).error.code); // AGENCY_NOT_FOUND / AGENT_NOT_FOUND
    const page = await r.json();
    yield* page.data;
    cursor = page.nextCursor;
  } while (cursor);
}

// one rep's practice calls, newest first — a second loop with 'real_call' reads their real calls
for await (const call of callsFor('2026-06-01T00:00:00Z', 'roleplay', { agentId: rep.agentId })) {
  console.log(call.id, call.drillKey, call.scoredAt);
}
```
</Tab>
</Tabs>

<Callout type="info">
  `GET /v1/calls` is a history read — it returns scored calls only, not in-progress ones. The
  [`call.scored` webhook](/backend/webhooks) is your notification for both practice and real calls;
  use this endpoint to render history and to reconcile.
</Callout>

## Detail — `GET /v1/calls/:callId`

Look up one call of either source by its public `id` (from a list row, a webhook `callId`, or the
SDK `ended` event). A call from another tenant returns `404 CALL_NOT_FOUND`, indistinguishable from
an unknown id.

```bash
curl https://app.useathos.ai/api/external/v1/calls/athos_call_GZ1DjOkZv_VEPoE-CJ8mp \
  -H "Authorization: Bearer $ATHOS_API_KEY"
```

## The `transcript`

A flat list of turns, in the order they were spoken:

```json
[
  { "role": "agent", "content": "Hi, this is Sam from the benefits line." },
  { "role": "beneficiary", "content": "Yeah, I saw something about the grocery card." }
]
```

| Field | Type | What it is |
| --- | --- | --- |
| `role` | `"agent"` or `"beneficiary"` | Who spoke. **`agent` is your rep** — the human being graded. **`beneficiary` is the customer** — the AI persona on a practice call, the real person on the line on a `real_call`. |
| `content` | string | What was said on that turn. |
| `startTime`, `endTime` | number *(optional)* | Turn boundaries in seconds from the start of the call. Present on `real_call` rows, not on roleplay calls — read them defensively. |

Get those two the wrong way round and every speaker label in your UI is inverted.

## Recording playback

**Branch on `audioUrlExpiresAt`, not on `audioUrl`.** When `audioUrlExpiresAt` is set, `audioUrl` is
a **short-lived signed URL** — it plays for about an hour and then stops working, and
`audioUrlExpiresAt` tells you exactly when. Use it directly in an `<audio>` element or a download
link, but **do not store it** in your database and do not email or embed it anywhere long-lived:
when you need it again, fetch the call again and you get a fresh one.

When `audioUrlExpiresAt` is `null`, the URL is not time-limited by us. Either the call carries a
stored recording URL (older practice calls do), or `audioUrl` is `null` too and there is nothing to
play — a call practised before recording was enabled, a real call whose recording was not archived,
or the rare case where a recording exists but could not be prepared for playback, which a later
request usually resolves.

A `real_call`'s `audioUrl` is a short-lived signed link to **Athos's own archived copy**
of the dialer recording, with `audioUrlExpiresAt` set — or `null` when no archive exists. It is
never the dialer's own recording URL.

## The `score` object

For every call, practice or real, `score` always has three fields, plus one optional:

| Field | Type | What it is |
| --- | --- | --- |
| `overallScore` | number | Overall call performance, **0–100** (higher is better). On a `real_call` the headline is **60–100** by construction. |
| `summary` | string | A short natural-language summary of the call. |
| `feedback` | string | Coaching feedback for the rep. |
| `complianceScorecard` | object *(optional)* | The call's compliance review, section by section, headed by a numeric `totalScore`. |

`summary` and `feedback` are always present, but either can be an **empty string**: on a very short
call, or when the analysis step didn't complete, Athos has no prose to give even though the call
scored.

<Callout type="info">
  **`complianceScorecard` is optional — check for it, don't assume it.** On practice calls it
  appears on Medicare Advantage drills only, and only when the call ran long enough to assess
  (roughly five minutes); a short MA call and every Final Expense call simply omit the key. On a
  real call it is present when the call was assessed for compliance. It is *absent*, not `null`, so
  `if ('complianceScorecard' in call.score)` (or a truthiness check) is the right guard. Its inner
  sections are graded content and may gain items over time — read `totalScore` and treat the rest as
  display detail.

  `totalScore` itself is normally present whenever the scorecard is, but it is **optional too**: in
  the rare case where the underlying total is not a usable number we leave the field out rather than
  send a `0`, because a fabricated zero is indistinguishable from a genuine failing compliance score.
  Treat an absent `totalScore` as *not assessed*, never as a zero; the section detail is still valid.
</Callout>
