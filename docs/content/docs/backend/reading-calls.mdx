---
title: Reading calls
description: List scored calls and fetch full detail, including the score object.
---

Two endpoints, both server-to-server with your API key: a slim **list** for history views, and a
full **detail** for one call's transcript and score.

## List — `GET /v1/calls`

Returns **scored** calls for your tenant, newest first (`endedAt` descending), cursor-paginated.

**Query parameters**

| Param | Required | Notes |
| --- | --- | --- |
| `from` | ✅ | Lower bound (ISO 8601) on when the call **ended**. |
| `to` | | Upper bound (ISO 8601) on when the call **ended**. |
| `source` | | Filter by source. Every call is `roleplay` today. |
| `externalUserId` | | Filter to one rep. |
| `externalAgencyId` | | Filter to one agency (a label, never an auth boundary). |
| `limit` | | Page size, default `50`, max `100`. |
| `cursor` | | Opaque token from a previous `nextCursor`. |

**Response** — a slim row per call (no score, no transcript):

```json
{
  "data": [
    {
      "id": "athos_call_GZ1DjOkZv_VEPoE-CJ8mp",
      "source": "roleplay",
      "externalUserId": "rep_8842",
      "externalAgencyId": "agency_chicago",
      "drillKey": "ma-full-sale",
      "startedAt": "2026-06-05T14:39:40.295Z",
      "endedAt": "2026-06-05T14:49:52.295Z",
      "durationSec": 612,
      "scoredAt": "2026-06-05T14:50:29.005Z"
    }
  ],
  "nextCursor": "eyJ0IjoxNzQ5…"
}
```

`nextCursor` is `null` on the last page. Pass it back as `cursor` to page through.

<Callout type="warn">
  **`from` and `to` filter on when the call *ended*, not on when it was scored**, and results come
  back newest-ended first. Scoring finishes some minutes after the call ends, so a call can become
  readable inside a window you have already read past. A watermark that only ever moves forward will
  silently skip those calls — on each poll, re-scan a window that overlaps the last one (an hour is
  plenty) and deduplicate on `id`.
</Callout>

<Tabs items={['curl', 'Node']}>
<Tab value="curl">
```bash
curl -G https://app.useathos.ai/api/external/v1/calls \
  -H "Authorization: Bearer $ATHOS_API_KEY" \
  --data-urlencode "from=2026-06-01T00:00:00Z" \
  --data-urlencode "limit=50"
```
</Tab>
<Tab value="Node">
```ts
async function* allCalls(from: string) {
  let cursor: string | null = null;
  do {
    const url = new URL('https://app.useathos.ai/api/external/v1/calls');
    url.searchParams.set('from', from);
    if (cursor) url.searchParams.set('cursor', cursor);
    const r = await fetch(url, { headers: { Authorization: `Bearer ${process.env.ATHOS_API_KEY}` } });
    const page = await r.json();
    yield* page.data;
    cursor = page.nextCursor;
  } while (cursor);
}

for await (const call of allCalls('2026-06-01T00:00:00Z')) {
  console.log(call.id, call.drillKey, call.scoredAt);
}
```
</Tab>
</Tabs>

<Callout type="info">
  `GET /v1/calls` is a history read — it returns scored calls only, not in-progress ones. Use the
  [webhook](/backend/webhooks) as your push signal and this endpoint as the backstop.
</Callout>

## Detail — `GET /v1/calls/:callId`

Look up one call by its public `id` (from a list row, a webhook `callId`, or the SDK `ended` event).
A call from another tenant returns `404 CALL_NOT_FOUND`.

```bash
curl https://app.useathos.ai/api/external/v1/calls/athos_call_GZ1DjOkZv_VEPoE-CJ8mp \
  -H "Authorization: Bearer $ATHOS_API_KEY"
```

**Response** (roleplay; abridged):

```json
{
  "id": "athos_call_GZ1DjOkZv_VEPoE-CJ8mp",
  "source": "roleplay",
  "status": "scored",
  "externalUserId": "rep_8842",
  "externalAgencyId": "agency_chicago",
  "drillKey": "ma-full-sale",
  "startedAt": "2026-06-05T14:39:40.295Z",
  "endedAt": "2026-06-05T14:49:52.295Z",
  "durationSec": 612,
```

## The `transcript`

A flat list of turns, in the order they were spoken:

```json
[
  { "role": "agent", "content": "Hi, this is Sam from the benefits line." },
  { "role": "beneficiary", "content": "Yeah, I saw something about the grocery card." }
]
```

| Field | Type | What it is |
| --- | --- | --- |
| `role` | `"agent"` or `"beneficiary"` | Who spoke. **`agent` is your rep** — the human being graded. **`beneficiary` is the AI customer** they practised against. |
| `content` | string | What was said on that turn. |
| `startTime`, `endTime` | number *(optional)* | Turn boundaries in seconds from the start of the call. Not present on roleplay calls today — read them defensively. |

Get those two the wrong way round and every speaker label in your UI is inverted.

## Recording playback

**Branch on `audioUrlExpiresAt`, not on `audioUrl`.** When `audioUrlExpiresAt` is set, `audioUrl` is
a **short-lived signed URL** — it plays for about an hour and then stops working, and
`audioUrlExpiresAt` tells you exactly when. Use it directly in an `<audio>` element or a download
link, but **do not store it** in your database and do not email or embed it anywhere long-lived:
when you need it again, fetch the call again and you get a fresh one.

When `audioUrlExpiresAt` is `null`, the URL is not time-limited by us. Either the call carries a
stored recording URL (older calls do), or `audioUrl` is `null` too and there is nothing to play — a
call practised before recording was enabled, or the rare case where a recording exists but could not
be prepared for playback, which a later request usually resolves.

## The `score` object

For a **roleplay** call, `score` always has three fields, plus one optional:

| Field | Type | What it is |
| --- | --- | --- |
| `overallScore` | number | Overall call performance, **0–100** (higher is better). |
| `summary` | string | A short natural-language summary of the call. |
| `feedback` | string | Coaching feedback for the rep. |
| `complianceScorecard` | object *(optional)* | The call's compliance review, section by section, headed by a numeric `totalScore`. |

`summary` and `feedback` are always present, but either can be an **empty string**: on a very short
call, or when the analysis step didn't complete, Athos has no prose to give even though the call
scored.

<Callout type="info">
  **`complianceScorecard` is optional — check for it, don't assume it.** It appears on Medicare
  Advantage drills only, and only when the call ran long enough to assess (roughly five minutes); a
  short MA call and every Final Expense call simply omit the key. It is *absent*, not `null`, so
  `if ('complianceScorecard' in call.score)` (or a truthiness check) is the right guard. Its inner
  sections are graded content and may gain items over time — read `totalScore` and treat the rest as
  display detail.

  `totalScore` itself is normally present whenever the scorecard is, but it is **optional too**: in
  the rare case where the underlying total is not a usable number we leave the field out rather than
  send a `0`, because a fabricated zero is indistinguishable from a genuine failing compliance score.
  Treat an absent `totalScore` as *not assessed*, never as a zero; the section detail is still valid.
</Callout>
