The External API is seven endpoints under a single base URL.

**Base URL:** `https://app.useathos.ai/api/external/v1`

## Endpoints

| Method & path | Auth | CORS | Purpose |
| --- | --- | --- | --- |
| `POST /agents` | API key | ❌ | [Register an agent](/backend/managing-agencies-and-agents), creating their agency if needed. |
| `GET /agents` | API key | ❌ | [Look agents up](/backend/managing-agencies-and-agents#look-up--get-v1agents) by any handle, or page the roster. |
| `PATCH /agencies/{agencyId}` | API key | ❌ | [Rename an agency](/backend/managing-agencies-and-agents#update-an-agency--patch-v1agenciesagencyid) or set your own id on it. |
| `POST /session` | API key | ❌ | [Mint a session token](/backend/minting-tokens) for the SDK. |
| `POST /roleplay/session` | Session token | ✅ | Redeem a token and start a call. **Called by the SDK**, not you. |
| `GET /calls` | API key | ❌ | [List scored calls](/backend/reading-calls) (cursor-paginated). |
| `GET /calls/{callId}` | API key | ❌ | [Get full call detail](/backend/reading-calls) (transcript + score). |

The six API-key endpoints are **server-to-server** and reject cross-origin requests. Only the SDK's
redeem endpoint accepts browser (CORS) requests. See [Authentication](/authentication).

## Conventions

- **Auth:** bearer token — `Authorization: Bearer <api-key-or-token>`.
- **Success:** returns the resource JSON **directly** (no envelope).
- **Errors:** `{ "error": { "code", "message", "requestId" } }`. Branch on `code` — see
  [error codes](/reference/errors).
- **Request id:** every response from a v1 endpoint carries `X-Athos-Request-Id`. Quote it in
  support tickets.
- **Rate limits:** none are enforced in v1. Poll `GET /calls` on a schedule rather than in a tight
  loop; the `call.scored` webhook is the notification.
- **Versioning:** the path is pinned to `/v1`. Breaking changes ship under a new version; `/v1` stays
  available for at least six months past any successor.

## OpenAPI spec

The full machine-readable contract is published as an OpenAPI 3.1 document:

<Cards>
  <Card title="Download openapi.yaml" href="/openapi.yaml">

  </Card>
</Cards>

Point any OpenAPI generator at it for a typed client:

```bash
npx @openapitools/openapi-generator-cli generate \
  -i https://docs.useathos.ai/openapi.yaml \
  -g typescript-fetch -o ./athos-client
```
